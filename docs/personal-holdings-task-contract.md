# 现有任务的个人持仓关联约定

先调用 read_current_holdings(journal_id="personal:gtht")，使用 effective_data、snapshot.occurred_at、原始ID和更正链。它优先于 remember 中的 current_portfolio_holdings。缺失、不完整、非分析日快照必须明确标记，不推定空仓或实时持仓，不从持仓差额生成交易。旧记忆只能作为标明日期的历史材料。

市场取数使用现有同花顺工具：get_limit_pools 的 limit_up、limit_down、limit_break、ladder；get_sector_board 的 search、membership、ranking、constituents；必要时 get_hot_stocks。复用同次运行数据，正确遍历服务端分页和工具输出分页，记录实际交易日期、来源、抓取时间、覆盖范围、失败。仅向市场接口发送证券代码，不发送数量、资金、账户标识和交易流水。已有工具回退须披露来源，不能混称同花顺。

盘后复盘与打板扫描增加“持仓板块风险”表：标的、当日涨跌幅、行业/概念及涨跌幅、超额百分点、同板块跌停/停牌候选、原文来源、待核查项。逆板块指同日涨跌方向相反；持仓浮盈亏不是当日涨跌幅。行业、概念、地域与指数标签分开。ETF先核实跟踪指数、成分日期和权重；不按名称猜成分、不把成分股事件等同ETF必跌。

龙头需注明可核查定义及日期（例如板块成交额或连板高度），热度不等于行业龙头。异常波动公告、拟停牌、实际停牌和复牌分开；依据公司/交易所原公告核实生效时间和原因。缺公告覆盖时写待核查，不写“无风险”。同板块事件只说明潜在关联，不证明影响方向或幅度。

记录事实、分析推断和用户决定分别呈现。交易习惯分析使用可追溯交易记录及事前计划，缺事前理由不能认定情绪化。不得自动交易。保留原任务时间、报告和投递设置；本次手动验收不发送微信。
